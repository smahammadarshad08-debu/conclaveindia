# AccessMap India — Product & Engineering Roadmap (2025–2026)

This roadmap outlines key milestones, planned integrations, and technological enhancements for **AccessMap India**.

---

## Milestone 1: Core Navigation & Compliance (Completed - Q3 2025)
- [x] MoHUA Harmonised Guidelines 2021 gradient and tactile compliance filters.
- [x] OpenStreetMap & OSRM multi-modal pedestrian routing engine.
- [x] Interactive mobile bottom sheet UI with 3 snap stop positions.
- [x] High-accuracy W3C GPS location tracker and quick-navigation FAB.
- [x] Turn-by-turn live navigation HUD with spoken audio prompts.

---

## Milestone 2: Transit GTFS-Flex & Metro Ingestion (Current - Q4 2025)
- [ ] Direct GTFS-Pathways ingestion for Delhi Metro (DMRC), Mumbai Metro (MMRDA), and Bengaluru (Namma Metro).
- [ ] Real-time lift/escalator maintenance alerts feed integration via municipal APIs.
- [ ] Multi-lingual speech synthesis support (Hindi, Tamil, Telugu, Bengali, Marathi, and Kannada).
- [ ] Offline vector tile caching via IndexedDB for low-connectivity subway corridors.

---

## Milestone 3: Crowdsourced Computer Vision & Field Audits (Q1 2026)
- [ ] Client-side WebAssembly camera module for automated sidewalk curb and ramp gradient measurement.
- [ ] Direct export bridge to municipal GIS databases (NIC, Smart Cities Mission).
- [ ] Bluetooth Low Energy (BLE) beacon integration for indoor station concourse guidance.
